# 万象 Myriad

> 你的上网起点，一页尽万象。

万象是一个替换浏览器新标签页的扩展：分组网格、文件夹、Dock、多引擎搜索、时钟与农历，配色和交互沿用 [zxabinbina.cc.cd](https://zxabinbina.cc.cd) 的设计语言。数据默认只存在本机，可随时导出为 JSON；也可以连接自己部署的后端 [myriad_api](https://github.com/zxaBinbina/myriad_api) 在多台设备之间同步。

> 目前处于 **M3 · 小组件** 开发阶段：天气、每日一言、倒数日、网站监控、Minecraft、汇率、待办与便签已可使用；翻译、GitHub 和部分进阶功能继续开发。

## 功能

- **主题**：芙芙蓝 / 胡桃红两套配色 × 深色 / 浅色 / 跟随系统；首帧同步读取，无闪烁
- **背景**：纯色画布、自定义图片或视频壁纸（上传 / 链接；视频静音循环，后台自动暂停）、Bing 每日一图、每日随机风景（Picsum）、Unsplash 每日一图（需同步服务）；按「配色 × 明暗」四种组合分别设置，可调模糊、遮罩、亮度
- **分组**：顶部胶囊或左侧侧栏（可收起），滑动 / 淡入切换，支持滚轮切换和 `Alt+1…9`
- **网格**：拖动排序，把图标拖到一起合成文件夹；图标尺寸、圆角、名称显示可调；网格模式 / 极简模式（小组件收进仪表盘）
- **Dock**：所有分组共用，常驻 / 自动隐藏 / 隐藏，macOS 式放大或轻微上浮
- **图标回退链**：自建图标代理（连接同步服务时）或第三方 favicon 服务（Google / DuckDuckGo / icon.horse / 直连）→ 内置图标库（Simple Icons、Lucide）→ 上传图片 → 文字图标
- **搜索**：内置常用引擎，可添加自定义引擎（`%s`）；点击图标、前缀（如 `gh vue`）、Tab 三种切换方式；联想来自引擎接口、搜索历史和已有快捷方式
- **快捷键**：`\` 或 `/` 聚焦搜索，页面上直接打字进入搜索，`Esc` 清空，`Alt+,` 打开设置，均可自定义
- **时钟**：搜索框上方的数字时钟（可隐藏，只留日期），12 / 24 小时制，多时区；公历、星期、节日、第几天 / 第几周；中国用户默认显示农历、干支、节气与法定节假日
- **小组件**：日历、指针时钟、天气、每日一言、倒数日、网站监控、Minecraft、汇率、待办与 Markdown 便签；支持共享清单、任务提醒和可选端到端加密，网络缓存只保存在本机
- **导入导出**：首次打开可从浏览器书签导入（勾选文件夹，顶层 → 分组，下一层 → 文件夹）；完整数据 JSON 导入导出，上传的图标和壁纸一并带走
- **中英双语**：默认跟随浏览器语言
- **同步**（连接 myriad_api）：基于 Yjs 的本地优先同步，断网照常使用、恢复后自动补传；同一浏览器的多个标签页即时互通；两台设备把同一项改成不同值时弹窗选择（可把某个设置设为「仅本机」）；同步范围可逐项改为只在本机生效；服务器每日备份，导入和回滚前自动多备份一份，可一键回滚

## 安装

尚未上架商店。从源码构建：

```bash
git clone https://github.com/zxaBinbina/myriad.git
cd myriad
npm install
npm run build        # 产出 apps/extension/.output/chrome-mv3 与 firefox-mv3
```

- **Chrome / Edge 等 Chromium 浏览器**：打开 `chrome://extensions`，开启「开发者模式」，点「加载已解压的扩展程序」，选择 `apps/extension/.output/chrome-mv3`。
- **Firefox**：打开 `about:debugging#/runtime/this-firefox`，「临时载入附加组件」，选择 `apps/extension/.output/firefox-mv3/manifest.json`。

### 权限

| 权限                                                             | 用途                          | 何时申请                             |
| ---------------------------------------------------------------- | ----------------------------- | ------------------------------------ |
| `storage`                                                        | 保存快捷方式与设置            | 安装时                               |
| 搜索联想接口的主机权限（Google、Bing、百度、DuckDuckGo、B 站）   | 搜索建议、Bing 每日壁纸       | 安装时                               |
| `bookmarks`                                                      | 导入书签                      | 点「导入书签」时临时申请             |
| `geolocation`                                                    | 天气的浏览器定位              | 安装时授权；只在点击定位时读取位置   |
| `notifications`、`alarms`                                        | 待办通知及扩展后台定时提醒    | 首次保存启用通知提醒的任务时申请     |
| 小组件数据源的主机权限                                           | 读取天气 / 一言 / 状态 / 汇率 | 搜索城市或点「允许访问数据源」时申请 |
| 同步服务地址的主机权限（如 `https://myriad.zxabinbina.cc.cd/*`） | 同步、备份、图标代理          | 点「连接」时只申请这一个来源         |

Chrome 不允许把 `geolocation` 声明为可选权限，因此它与 `storage` 一样放在必需权限中；扩展只在点击「使用浏览器定位」时调用定位 API，不会在页面打开时自动读取位置。

### 同步

1. 部署后端：见 [myriad_api](https://github.com/zxaBinbina/myriad_api) 的说明。Worker + D1 即可使用，无需开通 Access 或 R2。
2. 运行后端的 `npm run token:create`，部署生成的令牌校验值。
3. 重新加载扩展，打开「设置 → 同步」，选择「连接令牌」，填写服务地址和后端 `.local/connection-token.txt` 中的令牌，点「连接」并允许访问该地址。

连接令牌只保存在本机，不会出现在导出文件里，也不会同步。已有的 Access Service Token 配置会在升级后保留，仍可选择「Cloudflare Access」连接。

如果云端已有数据，连接时询问使用云端内容还是上传本机内容。上传前、导入前和回滚前会备份；无 R2 时备份与上传文件分块保存在 D1，单个对象最多 10MiB。更大的视频壁纸可在本机使用，或改用视频链接。

### 小组件

在网格空白处右键 →「添加小组件」选择组件；右键组件可调整尺寸，右上角的设置按钮可修改内容。升级不会在已有分组中自动插入新组件。卡片保留组件标题，去掉了编号英文小标签。

- **天气**：先搜索城市（也可填写经纬度或使用浏览器定位），可保存多个城市、切换 °C / °F、开关体感 / 预报 / AQI / 日出日落。宽卡片显示 7 天预报，高卡片增加逐小时预报；使用 Open-Meteo 免费来源，30 分钟缓存。连接 Worker 后可选按 IP 粗略定位。AQI 使用美国标准，上游缺失时隐藏。
- **每日一言**：按设备本地日期每天获取一次，可选分类；点击句子复制，爱心收藏，设置中可改为每天从收藏中选一句。收藏保存在各组件的配置中，随数据同步与 JSON 导出。
- **倒数日**：默认「悠哉世界开服纪念日」（2025-06-20），每年循环并显示开服天数；可编辑事件、起始日、每年 / 每月 / 每周循环，或关闭循环查看已过去的天数。循环碰到短月使用月末，后续月份恢复原始日号；日期按主时钟时区计算，不受夏令时影响。
- **网站监控**：默认读取悠哉世界现有状态服务，可配置状态和历史接口。小尺寸显示总体状态，较大尺寸显示服务延迟、节点 CPU / 内存、24 小时可用率和服务历史折线；只在打开页面或手动刷新时获取，不自动轮询，刷新遵守来源的 `refreshAfterMs`。
- **Minecraft**：默认悠哉世界。在组件设置中选择 **Java 版 / 基岩版**，只需填写服务器地址（如 `mc.example.com` 或 `mc.example.com:25566`），无需搭建状态服务或填写 Key。可显示在线状态、人数、版本、延迟、图标、彩色 MOTD、玩家样本与头像，以服务器实际返回内容为准。配置 Worker 时 Java 优先 SLP 握手，TCP 连接失败后退回 mcstatus.io；基岩版与没有 Worker 的情况使用 mcstatus.io。
  - 选择「状态接口（兼容悠哉世界）」时，可读取独立 Minecraft JSON 或含 `minecraft` 的 JSON，不要求完整网站监控数据。接口失败或状态未知时，按上方地址使用所选 Java / 基岩版备选，默认 Java，可关闭；明确离线不会被备用来源覆盖。查询失败显示「无法查询」。
  - 人数曲线只读取已配置的历史接口，未配置则隐藏；Worker 不记录历史。可添加复制地址、官网等操作，默认没有快捷操作。
- **汇率**：基准币种按浏览器时区推断，支持换算、交换币种和近 30 天走势。Frankfurter → ExchangeRate-API → Currency API 自动回退，无需 Key；主来源没有历史时每五天取样，缺少数据时隐藏走势。设置中可开启常用加密货币。数据缓存 12 小时，显示来源及其报价日期。
- **待办与便签**：同一清单可放在多个分组，任务与 Markdown 便签共享内容。顶部右侧加号为唯一添加入口，打开表单后只填名称即可回车保存，其他选项按需填写。支持截止日期 / 时间、优先级与颜色、子任务、每日 / 每周 / 每月 / 每年重复、拖拽排序、完成折叠或归档。重复任务在完成时生成下一次，短月保留原始日号，过期完成跳过遗漏日期。任务日期使用主时钟时区，未填时间的提醒按 09:00 计算。截止任务默认显示在日历与倒数日，各组件可关闭联动。

### 待办提醒与加密

任务编辑中选择截止时或提前提醒，保存时申请通知权限。扩展使用后台 alarms，关掉新标签页仍可提醒；浏览器完全关闭时不运行，重新打开后补发最近 24 小时内未发送的提醒。网页版只在页面打开时通知；拒绝权限仍保存任务并显示页面高亮。完成或删除任务会撤销待发提醒，每个任务的同一次提醒在本机只发送一次。

组件右上角「加密与密钥」可将整个清单改为端到端加密：标题、任务及子任务、Markdown 便签使用 AES-GCM，当前同步数据和普通 JSON 导出只包含密文。扩展密钥独立保存在 `chrome.storage.sync`，由浏览器账号同步；网页版密钥只存本机，需要单独导出 / 导入密钥，或使用相同口令解锁。口令通过 PBKDF2-SHA256（600,000 次、随机盐）派生密钥，原口令不保存。普通 JSON 备份不包含密钥，导入加密清单后没有匹配密钥时显示锁定。

**开启加密不会清除此前云端历史或备份中的明文。** 模式转换创建新的清单记录并更新所有共享引用，以防离线设备把明文和密文结构合并到一起。清单内容加密，记录 ID、排序及组件配置仍用于同步；通知标题与消息在设备上的提醒队列中为明文。密钥丢失且没有口令或单独密钥备份时，无法恢复加密内容。

数据组件只在当前分组、组件处于视口内且页面在前台时加载；隐藏即取消请求、停止刷新。天气、一言、汇率与自定义 Minecraft 优先使用已配置的 Worker，也可在组件设置里改为直连；网站监控与默认悠哉世界直连现有状态服务并共享缓存。公开数据请求不携带连接令牌，断网时尽量显示本机缓存。

尚未实现和风天气 / 预警、农历倒数日 / 自动法定假期、倒数日独立事件提醒、翻译和 GitHub；完整 M3 进度见 [项目进度](AGENTS.md)。

### 新标签页的焦点

Chrome 打开扩展的新标签页时，键盘焦点留在地址栏，直接打字会输入到地址栏里。设置 →「搜索」里的 **打开新标签页时聚焦搜索框**（默认关闭）会让页面重新加载一次以取得焦点，这样直接打字就能进入搜索框；代价是地址栏会显示扩展地址。

## 开发

需要 Node.js 22 以上。

| 命令                            | 说明                                                      |
| ------------------------------- | --------------------------------------------------------- |
| `npm run dev`                   | 启动 WXT 开发模式（Chromium，热更新）                     |
| `npm run dev:firefox`           | Firefox 开发模式                                          |
| `npm run dev:web`               | 在普通网页里运行界面（localStorage 存储），调试样式最方便 |
| `npm run build` / `npm run zip` | 构建 / 打包 Chrome 与 Firefox 两个版本                    |
| `npm run typecheck`             | 全部工作区类型检查                                        |
| `npm test`                      | 单元测试（Vitest）                                        |
| `npm run format`                | Prettier 格式化                                           |

浏览器测试脚本（需要 Python 版 Playwright）：

```bash
npm run build:web && npm run preview -w @myriad/playground -- --port 4180 &
python3 scripts/check-ui.py          # 网页版主要交互，截图存到 artifacts/
python3 scripts/check-widgets.py     # 固定上游数据，检查 M3 首批设置、缓存、跨日与可见性
python3 scripts/check-services.py    # 状态 / Minecraft / 汇率、刷新约束与免费来源回退
python3 scripts/check-minecraft.py   # 仅地址查询、状态 JSON 与备选、缓存和后台取消
python3 scripts/check-memo.py        # 共享清单、重复任务、提醒、Markdown 清理与跨设备解锁

python3 -m playwright install chromium
python3 scripts/check-extension.py   # 在真实扩展环境加载新标签页
python3 scripts/check-sync.py        # 两个隔离页面联调本地 Worker，见脚本说明
```

### 与后端本地联调

```bash
# 在 myriad_api 仓库
cp .dev.vars.example .dev.vars   # 开启 DEV_AUTH_BYPASS，只对 localhost 生效
npm run dev                      # http://127.0.0.1:8787

# 在本仓库
npm run dev:web                  # 设置 →「同步」，服务地址填 http://127.0.0.1:8787，点「连接」
```

用浏览器的两个独立配置（或无痕窗口）各开一个页面，就能模拟两台设备。

### 目录结构

```
packages/
  core/         # @myriad/core：数据模型、存储接口、导入导出、书签转换、搜索引擎、农历与节假日、同步引擎（sync/）
  ui/           # @myriad/ui：Vue 3 组件（MyriadApp 入口）、状态、主题样式、i18n
apps/
  extension/    # WXT 扩展：新标签页入口、chrome.storage 适配、书签权限
  playground/   # 网页版预览，用于开发与浏览器测试
docs/           # Logo（SVG 与 512px PNG）
scripts/        # Playwright 冒烟测试
```

`@myriad/ui` 不直接访问浏览器扩展 API，而是通过 `MyriadPlatform` 接口（存储、书签、版本号等）由宿主注入，因此同一套界面可以跑在扩展、网页和之后的个人主页 `/myriad` 中。
